# @intexuraos/http-contracts

Shared OpenAPI and Fastify JSON schemas describing inter-service request/response shapes.

## Contract

- **Layer:** leaf
- **Dependencies:** None (leaf)
- **Exports:** `./src/index.ts` (source-exports — no `dist/` emission)

## Usage

```ts
import { ServiceErrorSchema } from '@intexuraos/http-contracts';
```

For full API documentation, see [`docs/packages/http-contracts/README.md`](../../docs/packages/http-contracts/README.md).
