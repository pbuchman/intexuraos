# @intexuraos/infra-notion

Notion API client wrapper, error mapping, and page-retrieval helpers.

## Contract

- **Layer:** infra-wrapper
- **Dependencies:** `@intexuraos/common-core`
- **Exports:** `./src/index.ts` (source-exports — no `dist/` emission)

## Usage

```ts
import { NotionClient } from '@intexuraos/infra-notion';
```

For full API documentation, see [`docs/packages/infra-notion/README.md`](../../docs/packages/infra-notion/README.md).
