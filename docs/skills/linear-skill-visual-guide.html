Create Draft PR

Continuous Execution Loop

  • One branch for parent (feature/INT-XXX)
  • Execute children in tier order (0 → 1 → 2 → ...)
  • After each child: commit, push, update PR description
  • No stopping between children
  • PR tracks progress with status table

Why Two Cycles?

  • Phase 1 ensures task is properly analyzed and enriched
  • Complex tasks get split into manageable children
  • STOP points prevent runaway automation
  • Labels act as state machine transitions
  • Each cycle is idempotent (safe to retry)
