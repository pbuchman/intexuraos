# Web App Reference

The web app is the IntexuraOS dashboard. It provides code task views, integrations, calendar and Linear pages, notes, bookmarks, research review, worker status, and settings.

## Current Scope

- No command/action inbox.
- No retired action execution UI.
- Share Target creates notes/bookmarks through current APIs.
- Service URLs come from `apps/web/service-manifest.json` and generated config.

## Important Files

- `apps/web/service-manifest.json`
- `apps/web/src/App.tsx`
- `apps/web/src/config.generated.ts`
- `apps/web/src/config.ts`
- `apps/web/src/services/`

Use icon and compact operational UI patterns already established in the dashboard.
