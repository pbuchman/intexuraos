# Runbook - INT-1636 Hetzner Web/Static Cutover

## Scope

Checklist for moving `https://intexuraos.cloud` web/static delivery to
Hetzner while retaining GCP buckets and the current GCP web bucket/load
balancer for rollback.

## Source Of Truth

- `apps/web/service-manifest.json` is the service routing source of truth.
  Use each service `apiPath` for the public web API base.
- `apps/web/src/config.generated.ts` is generated by
  `scripts/generate-service-wiring.mjs` and exposes `WEB_SERVICE_URLS`.
- `apps/web/src/config.ts` consumes `WEB_SERVICE_URLS`. In production, all
  `INTEXURAOS_*_URL` values are baked into the Vite bundle.
- `apps/web/cloudbuild.yaml` and `cloudbuild/cloudbuild.yaml` must run the cutover build with
  `_WEB_SERVICE_URL_MODE=public-api` and
  `_WEB_PUBLIC_BASE_URL=https://intexuraos.cloud`.

## Retained GCP Buckets

All retained buckets are in project `intexuraos-dev-pbuchman`. The `-dev`
suffix is current production infrastructure naming.

| Purpose                  | Retained bucket or route                         | Cutover handling                                                                 |
| ------------------------ | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| GCP web rollback         | `gs://intexuraos-web-dev` plus GCP LB IP         | Leave intact. Record `terraform output web_app_load_balancer_ip` before cutover. |
| Shared content           | `gs://intexuraos-shared-content-dev`             | Hetzner must serve `/share/*` from this bucket or an explicitly documented equivalent. `/share/research/x.html` maps to bucket object `research/x.html`. |
| Generated images         | `gs://intexuraos-images-dev`                     | Hetzner must serve `/images/*` from this bucket or an explicitly documented equivalent. |
| Static assets            | `gs://intexuraos-static-assets-dev`              | Keep public direct GCS URLs available, for example `https://storage.googleapis.com/intexuraos-static-assets-dev/...`. |
| WhatsApp media           | `gs://intexuraos-whatsapp-media-dev`             | Keep private signed-URL access. No public Cloudflare route. Do not change `INTEXURAOS_WHATSAPP_MEDIA_BUCKET`. |
| Cloud Functions source   | `gs://intexuraos-functions-source-dev`           | Retain for function deploy/rollback. No public route. |

## Pre-Cutover

- [ ] Open a cutover window and pause web deploys until smoke checks pass.
- [ ] Record current Cloudflare `intexuraos.cloud` DNS records, proxy status,
  and TTL values.
- [ ] Record GCP rollback values:

```bash
cd terraform/environments/dev
terraform output web_app_load_balancer_ip
terraform output web_app_bucket_name
terraform output static_assets_bucket_name
terraform output whatsapp_media_bucket_name
terraform output cloud_functions_source_bucket
```

- [ ] Record the current provider callback URLs before changing them. Any
  `*.run.app` callback URL is rollback-only documentation after this point.
- [ ] Set Cloudflare DNS TTL to `300` seconds during the window if records are
  DNS-only. If Cloudflare proxy stays enabled, record that proxy mode and plan a
  cache purge at cutover and rollback.
- [ ] Build the web bundle with `_WEB_SERVICE_URL_MODE=public-api` and
  `_WEB_PUBLIC_BASE_URL=https://intexuraos.cloud`.
- [ ] Confirm the planned service URL env values before the build:

```bash
node scripts/generate-service-wiring.mjs --public-env --base-url https://intexuraos.cloud
```

- [ ] Check the candidate production web artifact has no Cloud Run URLs:

```bash
rg -n "run\.app|a\.run\.app" apps/web/dist apps/web/.env
```

Expected: no matches. Matches in rollback documentation do not count; matches
in `apps/web/dist` or `apps/web/.env` block cutover.

- [ ] Configure Hetzner static serving:
  - [ ] `/` and `/index.html` return the web bundle.
  - [ ] Hash routes work via `/#/...`; clean SPA paths are not required.
  - [ ] `/healthz` returns `200` without auth or redirect.
  - [ ] `index.html`, `sw.js`, and `manifest.webmanifest` are not cached.
  - [ ] Hashed `/assets/*.js`, `/assets/*.css`, and `workbox-*.js` use
        `Cache-Control: public, max-age=31536000, immutable`.
  - [ ] `/api/*` reverse proxies to the service matching each manifest
        `apiPath` and strips that matched prefix before forwarding upstream.
  - [ ] `/share/*` routes to retained shared-content bucket handling.
  - [ ] `/images/*` routes to retained generated-images bucket handling.
  - [ ] The PWA navigation fallback excludes `/share/*` and `/images/*`.
  - [ ] `X-Forwarded-Proto: https` and `X-Forwarded-Host: intexuraos.cloud`
        are sent to upstream services.

URLs unless a replacement alias is explicitly documented before cutover.

| Auth0 SPA app       | Allowed Callback URLs                | `https://intexuraos.cloud`                                                             | Keep `https://dev.intexuraos.cloud` only if the same tenant serves dev. No `*.run.app`. |
| Auth0 SPA app       | Allowed Logout URLs                  | `https://intexuraos.cloud`                                                             | Same dev-domain note as above. |
| Auth0 SPA app       | Allowed Web Origins                  | `https://intexuraos.cloud`                                                             | Same dev-domain note as above. |
| Auth0 ChatGPT app   | Authorization URL                    | `https://intexuraos.cloud/api/user/auth/oauth/authorize`                               | Only if the ChatGPT Action app is active. |
| Auth0 ChatGPT app   | Token URL                            | `https://intexuraos.cloud/api/user/auth/oauth/token`                                   | Must share the same root domain as Authorization URL. |
| Auth0 ChatGPT app   | Allowed Callback URLs                | ChatGPT-provided `https://chat.openai.com/aip/.../oauth/callback` or `https://chatgpt.com/aip/.../oauth/callback` | Not an IntexuraOS domain. |
| Firebase Auth       | Authorized domains                   | `intexuraos.cloud`                                                                     | Keep the Firebase `authDomain` secret value from Terraform; do not replace it with the web domain. |

## Cutover

- [ ] Deploy the verified web artifact to Hetzner.
- [ ] Verify Hetzner origin directly before DNS, using a hosts-file override or
  direct origin test with `Host: intexuraos.cloud`.
- [ ] Switch provider callbacks/allowlists to the values above.
- [ ] In Cloudflare, point `intexuraos.cloud` apex records to Hetzner IPs.
  Leave `www` unchanged for this PR unless an approved follow-up adds
  `www.intexuraos.cloud` certificate and nginx host support.
- [ ] Preserve the pre-recorded Cloudflare proxy mode unless the cutover owner
  intentionally changes it.
- [ ] Purge Cloudflare cache for:
  - `/`
  - `/index.html`
  - `/sw.js`
  - `/manifest.webmanifest`
  - `/assets/*`
- [ ] Keep Cloudflare TTL at `300` until rollback risk is closed.

## Smoke Checks

- [ ] Static health:

```bash
curl -fsS https://intexuraos.cloud/healthz
```

- [ ] Web shell and cache headers:

```bash
curl -fsSI https://intexuraos.cloud/
curl -fsSI https://intexuraos.cloud/index.html
curl -fsSI https://intexuraos.cloud/manifest.webmanifest
curl -fsSI https://intexuraos.cloud/assets/<current-hashed-asset>.js
```

- [ ] Browser load:
  - [ ] `https://intexuraos.cloud/` loads.
  - [ ] `https://intexuraos.cloud/#/inbox` loads after refresh.
  - [ ] Auth0 login redirects back to `https://intexuraos.cloud`.
  - [ ] Pages using Firebase listeners authenticate and stream updates.

- [ ] API proxy health for every manifest path:

```bash
jq -r '.services[].apiPath' apps/web/service-manifest.json |
while read -r api_path; do
  curl -fsS "https://intexuraos.cloud${api_path}/health"
done
```

- [ ] Confirm production web artifact still has no Cloud Run URLs:

```bash
rg -n "run\.app|a\.run\.app" apps/web/dist apps/web/.env
```

- [ ] Retained bucket routes:

```bash
curl -fsSI https://intexuraos.cloud/share/research/<known-shared-file>.html
curl -fsSI https://intexuraos.cloud/images/<known-generated-image>
curl -fsSI https://storage.googleapis.com/intexuraos-static-assets-dev/branding/exports/primary/logo-primary-light.png
```

- [ ] Provider callbacks:
  - [ ] GitHub OAuth connection flow completes and returns to
        `/#/settings/github?oauth_success=true`.
  - [ ] Linear webhook test delivery returns `2xx`.
  - [ ] WhatsApp webhook verification succeeds, then a test inbound message is
        received.

## Rollback

- [ ] Roll back if static delivery, auth, callbacks, `/api/*`, `/share/*`, or
  `/images/*` fails and cannot be fixed inside the window.
- [ ] Restore Cloudflare apex records to the recorded GCP LB IP. `www` should
  not have changed in this cutover; if it was changed by an approved follow-up,
  restore it to the recorded pre-cutover value.
- [ ] Restore the recorded Cloudflare proxy mode and keep TTL at `300`.
- [ ] Purge Cloudflare cache for `/`, `/index.html`, `/sw.js`,
  `/manifest.webmanifest`, and `/assets/*`.
- [ ] Restore provider callbacks to the recorded pre-cutover values. `*.run.app`
  URLs are allowed only for this rollback step and must not be baked into the
  next production web bundle.
- [ ] Verify rollback:

```bash
curl -fsSI https://intexuraos.cloud/
curl -fsS https://intexuraos.cloud/healthz
```

- [ ] Leave GCP buckets and GCP LB in place until a later cutover has been
  stable for at least one full business day.
- [ ] After stability, restore normal Cloudflare TTL/proxy policy and archive
  the exact rollback values with the cutover notes.
